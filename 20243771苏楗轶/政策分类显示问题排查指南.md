## 🛠️ 常见问题解决

### 问题1：后端返回空数组
**原因**：数据库中policy表的type字段为空
**解决**：
```sql
-- 查看有多少条数据的type为空
SELECT COUNT(*) FROM policy WHERE type IS NULL OR type = '';

-- 如果有数据，需要更新
UPDATE policy SET type = '未分类' WHERE type IS NULL OR type = '';
```

### 问题2：前端无法访问后端
**原因**：跨域问题或后端未启动
**解决**：
1. 确认后端已启动
2. 检查后端是否有 `@CrossOrigin(origins = "*")`
3. 检查防火墙设置

### 问题3：分类数量显示为0
**原因**：SQL查询问题
**检查**：后端日志中的SQL语句
