### 3. 政策分类统计

**重要变化**：不再使用policy_kind表

原来：
```sql
SELECT pk.Type_ID, pk.Type, COUNT(p.id)
FROM policy_kind pk
LEFT JOIN policy p ON pk.Type_ID = p.policy_kind_id
GROUP BY pk.Type_ID, pk.Type
```

现在：
```sql
SELECT type, COUNT(id) as policy_count
FROM policy
WHERE type IS NOT NULL AND type != ''
GROUP BY type
ORDER BY type
```
