## 🎯 核心功能实现说明

### 1. 多条件查询
支持四个查询条件的组合查询：
- 政策名称：模糊匹配
- 政策文号：模糊匹配
- 发文机构：模糊匹配
- 全文检索：在政策名称、正文、关键词中搜索

### 2. 政策分类树
- 从policy_kind表读取所有分类
- 使用LEFT JOIN统计每个分类下的政策数量
- 点击分类可筛选该分类下的政策
- 再次点击取消筛选

### 3. 政策列表
- 表头居中显示（政策名称、发文机构、颁布日期、政策分类、操作）
- 政策名称、发文机构左对齐
- 颁布日期、政策分类、操作居中显示
- 支持分页显示（默认每页10条）

### 4. 政策详情
- 显示政策完整信息（名称、文号、发文机构、日期、分类、范围、状态等）
- 显示政策正文内容
- 时效状态用颜色区分（有效=绿色，无效=红色）

## 📊 API接口文档

### GET /api/policyKinds
获取政策分类树及政策数量

**响应示例：**
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "typeId": "0100",
      "type": "综合",
      "policyCount": 1
    }
  ]
}
```

### GET /api/policies
查询政策列表（支持分页和多条件查询）

**参数：**
- policyName: 政策名称（可选）
- policyNumber: 政策文号（可选）
- publishOrg: 发文机构（可选）
- keyword: 全文检索（可选）
- policyKindId: 分类ID（可选）
- pageNum: 页码（默认1）
- pageSize: 每页条数（默认10）

### GET /api/policy/{id}
获取政策详情
