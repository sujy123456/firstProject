## ⚠️ 常见错误排查

### 错误1：Communications link failure
**原因**：MySQL服务未启动
**解决**：
```bash
# Windows
net start MySQL80  # 或你的MySQL服务名

# 检查MySQL是否运行
netstat -ano | findstr 3306
```

### 错误2：Access denied for user 'root'@'localhost'
**原因**：密码错误
**解决**：检查 application.properties 中的密码是否为 `123456`

### 错误3：Unknown database 'febs'
**原因**：数据库不存在
**解决**：
```sql
-- 创建数据库
CREATE DATABASE febs DEFAULT CHARACTER SET utf8 COLLATE utf8_general_ci;
```

### 错误4：Table 'febs.policy' doesn't exist
**原因**：policy表不存在
**解决**：确认您的数据库中确实有policy表

### 错误5：No qualifying bean of type 'com.example.mapper.PolicyMapper'
**原因**：Mapper未被扫描到
**解决**：已添加 @MapperScan 注解，重新启动即可

### 错误6：Invalid bound statement (not found)
**原因**：Mapper XML文件找不到
**解决**：
1. 检查文件是否在 `src/main/resources/mapper/` 目录
2. 检查 `mybatis.mapper-locations=classpath:mapper/*.xml` 配置
