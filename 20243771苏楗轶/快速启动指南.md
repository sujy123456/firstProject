# 快速启动指南

## 第一步：初始化数据库

在MySQL中执行以下命令（或使用MySQL Workbench等工具执行）：

```sql
-- 方式1：使用命令行
mysql -u root -p123456 < test_03/src/main/resources/sql/init.sql

-- 方式2：在MySQL客户端中执行
source C:\Users\苏\Desktop\河北省科技政策\test_03\src\main\resources\sql\init.sql
```

或者手动执行 `test_03/src/main/resources/sql/init.sql` 文件中的所有SQL语句。

## 第二步：启动后端服务

1. 用IDEA打开 `test_03` 项目
2. 等待Maven依赖下载完成（首次可能需要几分钟）
3. 找到 `src/main/java/com/example/Test03Application.java`
4. 右键点击文件，选择 "Run 'Test03Application'"
5. 等待控制台出现以下信息表示启动成功：
   ```
   Started Test03Application in X.XXX seconds
   ```

## 第三步：启动前端应用

1. 用HBuilder X打开 `河北省科技政策查询` 项目
2. 点击菜单栏 "运行" -> "运行到浏览器" -> 选择浏览器
3. 或者点击 "运行" -> "运行到手机或模拟器"
4. 前端应用将自动打开

## 第四步：测试系统

1. 在浏览器中访问后端API测试是否正常运行：
   ```
   http://localhost:8080/api/policyKinds
   ```
   应该返回政策分类列表

2. 在前端界面中：
   - 测试多条件查询功能
   - 点击左侧政策分类树筛选政策
   - 点击"查看"按钮查看政策详情
   - 测试分页功能

## 故障排查

### 问题1：后端启动失败 - 数据库连接错误
**解决方案**：
- 检查MySQL服务是否启动
- 检查 `application.properties` 中的数据库用户名和密码是否正确
- 确认数据库 `hebei_policy_db` 已创建

### 问题2：后端启动失败 - 端口被占用
**解决方案**：
- 修改 `application.properties` 中的 `server.port=8081`（或其他端口）
- 同时修改前端代码中的 `API_BASE` 地址

### 问题3：前端无法获取数据
**解决方案**：
- 检查后端服务是否正常运行
- 打开浏览器开发者工具（F12），查看Console和Network标签页的错误信息
- 确认API地址是否正确：`http://localhost:8080/api`

### 问题4：政策分类树显示数量为0
**解决方案**：
- 检查 `policy_kind` 表是否有数据
- 检查 `policy` 表中的 `policy_kind_id` 是否正确关联
- 重启后端服务

## 数据导入提示

如果您有完整的政策数据需要导入，可以：

1. 准备Excel或CSV格式的数据文件
2. 使用MySQL的 `LOAD DATA INFILE` 命令导入
3. 或使用第三方工具（如Navicat）导入数据
4. 确保数据中的 `policy_kind_id` 与 `policy_kind` 表中的 `Type_ID` 对应
