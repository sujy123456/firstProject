# 河北省科技政策查询系统 - 项目部署说明

## 项目结构

```
河北省科技政策/
├── test_03/                          # Spring Boot后端项目
│   ├── src/main/java/com/example/
│   │   ├── Test03Application.java   # 启动类
│   │   ├── controller/              # 控制器层
│   │   ├── entity/                  # 实体类
│   │   ├── mapper/                  # MyBatis Mapper接口
│   │   └── service/                 # 服务层
│   └── src/main/resources/
│       ├── application.properties   # 配置文件
│       ├── mapper/                  # MyBatis XML映射文件
│       └── sql/init.sql             # 数据库初始化脚本
└── 河北省科技政策查询/               # HBuilder X前端项目
    └── pages/
        ├── index/index.uvue         # 主页面
        └── detail/detail.uvue       # 政策详情页
```

## 部署步骤

### 1. 数据库初始化

1. 确保MySQL已安装并启动
2. 执行SQL脚本创建数据库和表：
   ```bash
   mysql -u root -p123456 < test_03/src/main/resources/sql/init.sql
   ```
   
   或者在MySQL客户端中手动执行 `init.sql` 文件中的SQL语句。

### 2. 后端项目配置

1. 使用IDEA打开 `test_03` 项目
2. 检查 `src/main/resources/application.properties` 中的数据库配置：
   ```properties
   spring.datasource.url=jdbc:mysql://localhost:3306/hebei_policy_db?useUnicode=true&characterEncoding=utf8&useSSL=false&serverTimezone=Asia/Shanghai
   spring.datasource.username=root
   spring.datasource.password=123456
   ```
3. 等待Maven依赖下载完成
4. 运行 `Test03Application.java` 启动后端服务
5. 后端服务将在 `http://localhost:8080` 启动

### 3. 前端项目配置

1. 使用HBuilder X打开 `河北省科技政策查询` 项目
2. 确保前端代码中API地址正确（默认：`http://localhost:8080/api`）
3. 运行项目到浏览器或手机模拟器

## API接口说明

### 1. 获取政策分类树
- **URL**: `GET /api/policyKinds`
- **响应**:
```json
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "typeId": "0100",
      "type": "综合",
      "policyCount": 10
    }
  ]
}
```

### 2. 查询政策列表（分页）
- **URL**: `GET /api/policies`
- **参数**:
  - `policyName`: 政策名称（可选）
  - `policyNumber`: 政策文号（可选）
  - `publishOrg`: 发文机构（可选）
  - `keyword`: 全文检索关键词（可选）
  - `policyKindId`: 政策分类ID（可选）
  - `pageNum`: 页码（默认1）
  - `pageSize`: 每页条数（默认10）
- **响应**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "list": [...],
    "total": 100,
    "pageNum": 1,
    "pageSize": 10,
    "totalPages": 10
  }
}
```

### 3. 获取政策详情
- **URL**: `GET /api/policy/{id}`
- **响应**:
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": "20220608001",
    "policyName": "河北省科技创新条例",
    "publishOrg": "河北省人民政府",
    "publishDate": "2022-06-08",
    "content": "政策正文内容..."
  }
}
```

## 功能说明

### 主界面功能
1. **顶部LOGO区**: 显示系统标题
2. **多条件查询区**: 
   - 政策名称查询
   - 政策文号查询
   - 发文机构查询
   - 全文检索
3. **左侧政策分类树**: 
   - 显示所有政策分类
   - 括号内显示该分类下的政策数量
   - 点击分类可筛选政策
4. **右侧政策列表**: 
   - 显示政策名称、发文机构、颁布日期、政策分类
   - 支持分页显示
   - 点击"查看"跳转详情页
5. **底部版权区**: 显示版权信息

### 政策详情页功能
- 显示政策完整信息
- 显示政策正文内容
- 返回按钮返回列表页

## 注意事项

1. **跨域问题**: 后端已配置 `@CrossOrigin(origins = "*")` 允许跨域访问
2. **数据库连接**: 确保MySQL服务已启动，账号密码正确
3. **端口配置**: 后端默认端口8080，如冲突可在 `application.properties` 中修改
4. **数据导入**: 示例数据已包含5条政策记录，实际使用时可导入完整数据

## 常见问题

### 1. 后端启动失败
- 检查MySQL是否启动
- 检查数据库连接配置是否正确
- 检查端口8080是否被占用

### 2. 前端无法获取数据
- 检查后端服务是否正常运行
- 检查API地址是否正确
- 浏览器控制台查看网络请求错误

### 3. 政策分类数量为0
- 确保已执行 `init.sql` 插入分类数据
- 确保政策表中有数据且 `policy_kind_id` 正确关联
